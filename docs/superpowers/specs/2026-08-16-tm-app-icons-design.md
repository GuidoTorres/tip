# TM app icons design

## Goal

Usar un monograma `TM` reconocible en la pestaña, instalación PWA, notificaciones y Google OAuth Branding.

## Identity

- Fondo coral `#d95747` y letras claras `#fffaf7`.
- Monograma exacto `TM.` centrado horizontal y verticalmente, ocupando aproximadamente el 65% del área disponible.
- El punto usa el mismo color claro y es menor que las letras.
- Mantener el wordmark textual `TipMe.` existente dentro de la aplicación.
- No modificar emails ni añadir un sistema de correo.

## Assets

- Añadir el icono SVG reconocido por Next.js para la pestaña.
- Actualizar la fuente vectorial y los PNG de 96, 192 y 512 píxeles usados por PWA y push.
- Mantener una variante maskable con área segura.
- Crear un PNG cuadrado de 512 píxeles para subir manualmente a Google Auth Platform → Branding.

## Verification

Verificar metadatos, manifest, dimensiones de los PNG y build de producción.
